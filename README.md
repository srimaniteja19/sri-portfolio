# Sri Maniteja Chinnam — Portfolio

A modern, minimalist portfolio site built with Next.js 16, TypeScript, and Tailwind CSS. Features a distinct warm amber/indigo theme with light and dark mode support.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Stack

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS 4**
- **Outfit** & **JetBrains Mono** fonts
